# Offside! 

A C/C++ (RayLib) 2 player offline football game based on the famous Pong game 

## how to play
Download the playable release from the release section, extract the folder and enjoy.

## How to compile
If you want to compile the source code, be sure to use a C++ compilator and link the file `libraylib.a` included in the `lib` folder.
